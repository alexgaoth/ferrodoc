\subsection{Why this exists}\label{why-this-exists}

Teams hold documents in \textbf{Word}, \emph{LibreOffice}, EPUB and markdown at the
same time. Getting between those formats is supposed to be boring. When it
is not boring, it is usually because something was silently dropped.

\begin{quote}
A conversion you cannot inspect is a conversion you cannot trust.

— every migration post-mortem, eventually
\end{quote}

\subsection{Running a conversion}\label{running-a-conversion}

Convert a directory in one pass:

\begin{verbatim}
find . -name '*.docx' -print0 |
  xargs -0 -P8 -I{} ferrodoc {} -t gfm -o {}.md
\end{verbatim}

The Python equivalent, for a pipeline that already has one:

\begin{verbatim}
import ferrodoc
with open("report.docx", "rb") as f:
    text = ferrodoc.convert(f.read(), "docx", "gfm")
\end{verbatim}

An indented code block, which is a different construct:

\begin{verbatim}
ferrodoc -f markdown -t html handbook.md
\end{verbatim}

\subsection{Awkward cases, on purpose}\label{awkward-cases-on-purpose}

Inline code with special characters: \verb!a | b!, \verb|<div>|, \verb|--flag|, and a
literal backtick: \verb|`|.

Text with entities \& symbols — an em dash, "curly quotes", an
ellipsis…, a non-breaking space, and unicode: café, naïve, Ω, 日本語.

\sout{Struck-through text} and text with a footnote.\footnote{Footnote bodies can contain \textbf{formatting} and a
\href{https://example.com}{link}.}

Five inlines no writer test used to reach through this file: underlined
text, small caps, a
span carrying an id and a class, and
H2O beside E=mc2. They are here because \verb|docs/gates.md|
claims \verb|--samples| keeps them found, and until this paragraph existed no
sample document contained one — the claim was wider than the corpus behind
it, which is the defect this file is supposed to catch.

A link with a title: \href{https://example.com/spec}{the spec}.
A bare autolink: \href{https://example.com/status}{https://example.com/status}. An email:
\href{mailto:ops@example.com}{ops@example.com}.

An image: \includegraphics[alt={the logo}]{logo.png}



Raw HTML block, which not every target format can hold.



Nested quoting:

Outer quote.

\begin{quote}
Inner quote, with a list:

\begin{itemize}
\tightlist
\item
one

two
\end{itemize}
\end{quote}
\end{quote}
